# FlowPy Studio

**Aprende Python mirando lo que hace tu programa.**

[Abrir FlowPy Studio](https://carlosgy13.github.io/flowpy-studio/)

FlowPy Studio es un espacio para practicar lógica de programación sin perderse entre líneas de código. Escribes Python, lo ejecutas y ves su recorrido en un diagrama de flujo. Si algo no queda claro, usa Debug y avanza paso a paso.

No necesitas instalar Python ni crear una cuenta: abre el enlace y empieza.

## Empieza en tres pasos

1. Abre **Ejemplos** o escribe tu propio código.
2. Pulsa **Ejecutar** para leer la salida y ver el diagrama.
3. Pulsa **Debug** cuando quieras ir línea por línea y observar las variables.

Si aparece un `input()`, la pregunta se muestra dentro de la salida. Escribe tu respuesta ahí y continúa; funciona también en los bucles.

## Qué encontrarás

- Diagramas de flujo para instrucciones, decisiones, bucles y funciones.
- Zoom, pantalla completa y bloques que puedes mover para ordenar el diagrama como prefieras.
- Ejemplos de `if`, `for`, `for` con `if`, NumPy, funciones e interacción con `input()`.
- Un modo Debug que muestra la línea actual, las variables y la salida que el programa ha producido hasta ese momento.
- Mensajes de error junto a la línea que necesita atención.
- Retos cortos para practicar condicionales, bucles y detección de errores.

## Para practicar

Prueba estas preguntas mientras usas la plataforma:

- ¿Qué ocurre si cambia la condición de un `if`?
- ¿Cuántas veces entra un `for`?
- ¿Qué variables se modifican dentro de un `while`?
- ¿Qué devuelve una función y en qué momento?

El editor y la posición de los bloques se guardan automáticamente en este navegador. Así puedes cerrar la página y continuar después desde el mismo equipo.

## Ejecutarlo en tu computadora

Si quieres colaborar con el proyecto o ejecutarlo localmente:

```bash
npm install
npm run dev
```

Después abre `http://localhost:5173`. Para generar la versión de producción:

```bash
npm run build
```

## Proyecto abierto

FlowPy Studio es público para que cualquiera pueda usarlo, revisarlo y proponer mejoras. Las contribuciones se hacen mediante *pull requests*; la rama principal está protegida para cuidar la versión que usan los estudiantes.
